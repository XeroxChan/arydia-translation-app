# Private Arydia Content

This folder is for private local content only.

Do not commit copyrighted Arydia material here, including:

- full rulebook text
- full Quick Start Guide text
- full card text
- map text
- scans or screenshots
- OCR output
- full Traditional Chinese translations of copyrighted source text

The public GitHub repository should only contain:

- app code
- data schemas
- glossary terms
- placeholder/demo content
- small safe examples
- documentation

Private local files can use names such as:

- `quick-start.private.json`
- `rulebook.private.json`
- `cards.private.json`
- `maps.private.json`

These files are ignored by Git.
