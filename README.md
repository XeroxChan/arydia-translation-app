# Arydia Bilingual Translation App

A private-use iPad-friendly web app for displaying Arydia game content in English and Traditional Chinese side by side.

## Goal

The goal of this project is to help me play Arydia more smoothly by building a searchable bilingual reference app.

This app focuses on:

- English / Traditional Chinese side-by-side display
- Consistent glossary terms
- iPad-friendly reading layout
- Private local content management
- Translation review workflow

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React
- Git / GitHub

## Current Features

- Project setup
- Glossary planning
- Quick Start Guide prototype planning

## Notes

This is a private fan-made learning project.  
Copyrighted Arydia text, scans, and translated content are not intended for public distribution.

## Content and Copyright Notice

This repository is intended to showcase the app structure, bilingual database design, UI, glossary system, and translation workflow.

It does not include full copyrighted Arydia rulebook text, card text, map text, scans, OCR output, or full translations.

Private translated content should be stored locally in ignored files such as `private-data/*.private.json` or `src/data/private/*.private.ts`.
