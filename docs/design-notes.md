# Design Notes

## Visual direction

The app should feel like a fantasy adventure reference book, suitable for reading on iPad during gameplay.

The design should be inspired by dark parchment, brass borders, and warm fantasy rulebook colours.

## Colour palette

- Ink background: `#1c1a17`
- Dark panel: `#2a241d`
- Parchment text: `#ece3d2`
- Muted parchment: `#b9a988`
- Brass: `#a9762f`
- Bright brass/gold: `#c98f3b`
- Deep brown: `#3a2b1c`

## UI principles

- English and Traditional Chinese should be easy to compare.
- Traditional Chinese should be slightly larger for readability.
- Layout should work well on iPad.
- Avoid clutter during gameplay.
- Use reusable components instead of styling each page separately.

## Copyright note

The app should use my own UI styling and should not include official Arydia scans, logos, or copyrighted rulebook content in the public repository.
