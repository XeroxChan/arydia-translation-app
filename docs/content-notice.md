# Content Notice

This project is a private-use bilingual reference database built for studying and organizing Arydia gameplay materials.

The public repository is intended as a portfolio-safe codebase. It should include the application structure, UI, data models, glossary terms, and placeholder/demo data only.

The repository should not include copyrighted Arydia source material, including full rulebook text, card text, map text, scanned images, OCR output, or full translations of those materials.

Full translated content, if used privately, should be stored only in local ignored files such as:

- `private-data/*.private.json`
- `src/data/private/*.private.ts`

These files are excluded from Git.
