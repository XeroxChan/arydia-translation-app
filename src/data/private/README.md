# Private Data Folder

This folder is reserved for local-only private data used during development.

Files in this folder should not be committed if they contain copyrighted Arydia text or full translations.

Suggested local-only filenames:

- `quickStartGuide.private.ts`
- `rulebook.private.ts`
- `cardLibrary.private.ts`
- `maps.private.ts`

The app's public repository should continue to use demo or placeholder data.
